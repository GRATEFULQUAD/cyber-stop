# Cyber Stop

A precision cyberpunk-themed stopwatch web app. Pitch-black background with a static 2,300-particle neon field, solid opaque-black glass controls with neon borders/glow, lap tracking with best/worst split highlighting, and keyboard shortcuts (Space = start/pause, L = lap, R = reset).

Fully local — no login, no accounts, no backend, no tracking. State (elapsed time + laps) persists across refresh via localStorage. PWA-installable and works fully offline.

## Develop

```
npm install
npm run dev
```

## Deploy

Import this repo into Vercel — zero configuration required, no environment variables needed.
